## Overview

For larger environments (50+ agents), deploy OSEye components across multiple machines with a message bus (Redis Streams or Kafka) for horizontal scaling.

## Architecture

```
┌──────────┐    ┌──────────┐    ┌──────────┐
│  Agent 1 │    │  Agent 2 │    │  Agent N │
└─────┬────┘    └─────┬────┘    └─────┬────┘
      │gRPC           │gRPC           │gRPC
      ▼               ▼               ▼
┌─────────────────────────────────────────────┐
│          Load Balancer (HAProxy/Nginx)      │
└──────────────────────┬──────────────────────┘
                       │
         ┌─────────────┼─────────────┐
         ▼             ▼             ▼
   ┌──────────┐  ┌──────────┐  ┌──────────┐
   │ Server 1 │  │ Server 2 │  │ Server 3 │
   └─────┬────┘  └─────┬────┘  └─────┬────┘
         │              │              │
         ▼              ▼              ▼
┌─────────────────────────────────────────────┐
│          Redis Streams / Kafka              │
└──────────────────────┬──────────────────────┘
                       │
         ┌─────────────┼─────────────┐
         ▼             ▼             ▼
   ┌──────────┐  ┌──────────┐  ┌──────────┐
   │ Worker 1 │  │ Worker 2 │  │ Worker N │
   │ (Rules)  │  │ (ML)     │  │ (TI)     │
   └─────┬────┘  └─────┬────┘  └─────┬────┘
         │              │              │
         ▼              ▼              ▼
┌─────────────────────────────────────────────┐
│     PostgreSQL (primary) + ClickHouse       │
└─────────────────────────────────────────────┘
```

## Components

| Component | Role | Scaling |
|-----------|------|---------|
| Server (FastAPI) | gRPC ingestion, REST API, WebSocket | Horizontal (stateless) |
| Workers | Rule engine, ML, TI, correlation | Horizontal by type |
| Redis Streams | Event bus | Cluster mode |
| PostgreSQL | Metadata, alerts, incidents | Primary + replicas |
| ClickHouse | Event storage (high-volume) | Sharded cluster |

## Configuration

### Bus Configuration

```bash
# Redis Streams (recommended for < 500 agents)
OSEYE_BUS_BACKEND=redis
OSEYE_REDIS_URL=redis://redis-cluster:6379/0

# Kafka (for > 500 agents)
OSEYE_BUS_BACKEND=kafka
OSEYE_KAFKA_BROKERS=kafka1:9092,kafka2:9092,kafka3:9092
```

### Worker Scaling

```bash
# Scale workers by type
OSEYE_WORKER_TYPES=normalizer,rule_engine,ml_engine,ti_engine,correlator
OSEYE_WORKER_CONCURRENCY=4
```

## Nginx / HAProxy Configuration

### Nginx (gRPC reverse proxy + REST API)

```nginx
# /etc/nginx/conf.d/oseye.conf

upstream oseye_grpc {
    least_conn;
    server oseye-server-1:50051;
    server oseye-server-2:50051;
    server oseye-server-3:50051;
}

upstream oseye_api {
    least_conn;
    server oseye-server-1:8000;
    server oseye-server-2:8000;
    server oseye-server-3:8000;
}

# gRPC (agent → server)
server {
    listen 50051 ssl http2;
    server_name oseye.example.com;

    ssl_certificate     /etc/nginx/certs/server.crt;
    ssl_certificate_key /etc/nginx/certs/server.key;
    ssl_client_certificate /etc/nginx/certs/ca.crt;
    ssl_verify_client on;
    ssl_protocols TLSv1.3;

    location / {
        grpc_pass grpcs://oseye_grpc;
        grpc_set_header X-Real-IP $remote_addr;

        # Streaming keepalive
        grpc_read_timeout 3600s;
        grpc_send_timeout 3600s;
    }
}

# REST API + Dashboard
server {
    listen 443 ssl http2;
    server_name oseye.example.com;

    ssl_certificate     /etc/nginx/certs/server.crt;
    ssl_certificate_key /etc/nginx/certs/server.key;
    ssl_protocols TLSv1.3 TLSv1.2;

    # API
    location /api/ {
        proxy_pass http://oseye_api;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket (dashboard real-time)
    location /ws/ {
        proxy_pass http://oseye_api;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 3600s;
    }

    # Dashboard UI
    location / {
        proxy_pass http://oseye-ui:5173;
    }
}
```

### HAProxy (alternative)

```nginx
# /etc/haproxy/haproxy.cfg

frontend grpc_in
    bind *:50051 ssl crt /etc/haproxy/certs/server.pem ca-file /etc/haproxy/certs/ca.crt verify required
    mode tcp
    default_backend oseye_grpc

backend oseye_grpc
    mode tcp
    balance leastconn
    server srv1 oseye-server-1:50051 check
    server srv2 oseye-server-2:50051 check
    server srv3 oseye-server-3:50051 check

frontend api_in
    bind *:443 ssl crt /etc/haproxy/certs/server.pem
    mode http
    default_backend oseye_api

backend oseye_api
    mode http
    balance roundrobin
    option httpchk GET /api/v1/health
    server srv1 oseye-server-1:8000 check
    server srv2 oseye-server-2:8000 check
    server srv3 oseye-server-3:8000 check
```

## Redis Streams Configuration

```bash
# Redis Cluster (3 masters + 3 replicas)
# Install on each node:
redis-server --port 7000 --cluster-enabled yes \
  --cluster-config-file nodes.conf --cluster-node-timeout 5000 \
  --appendonly yes --protected-mode no

# Create the cluster (run once)
redis-cli --cluster create \
  redis1:7000 redis2:7000 redis3:7000 \
  redis4:7000 redis5:7000 redis6:7000 \
  --cluster-replicas 1
```

OSEye server configuration:
```bash
OSEYE_BUS_BACKEND=redis
OSEYE_REDIS_URL=redis://redis1:7000,redis2:7000,redis3:7000/0
```

## Kafka Configuration

```yaml
# docker-compose.kafka.yml (or use managed Kafka)
services:
  kafka:
    image: confluentinc/cp-kafka:7.6
    environment:
      KAFKA_BROKER_ID: 1
      KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
      KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://kafka1:9092
      KAFKA_NUM_PARTITIONS: 12
      KAFKA_DEFAULT_REPLICATION_FACTOR: 3
      KAFKA_MIN_INSYNC_REPLICAS: 2
      KAFKA_LOG_RETENTION_HOURS: 168
```

OSEye server configuration:
```bash
OSEYE_BUS_BACKEND=kafka
OSEYE_KAFKA_BROKERS=kafka1:9092,kafka2:9092,kafka3:9092
OSEYE_KAFKA_TOPIC_PREFIX=oseye
OSEYE_KAFKA_CONSUMER_GROUP=oseye-workers
```

## PostgreSQL Configuration

```bash
# Primary setup
sudo -u postgres createdb oseye
sudo -u postgres createuser oseye --pwprompt

# Connection pooling with PgBouncer (recommended for > 100 agents)
# /etc/pgbouncer/pgbouncer.ini
[databases]
oseye = host=localhost port=5432 dbname=oseye

[pgbouncer]
listen_port = 6432
pool_mode = transaction
max_client_conn = 1000
default_pool_size = 50
```

OSEye server configuration:
```bash
OSEYE_DB_BACKEND=postgresql
OSEYE_DB_URL=postgresql+asyncpg://oseye:PASSWORD@pgbouncer:6432/oseye
OSEYE_DB_POOL_SIZE=10
OSEYE_DB_MAX_OVERFLOW=20
```

## High Availability

- **Server**: deploy 3+ instances behind a load balancer (stateless — all state in Redis/PostgreSQL)
- **PostgreSQL**: primary + streaming replica with automatic failover (Patroni)
- **Redis**: Redis Cluster (3 masters + 3 replicas)
- **Workers**: stateless, auto-restart via systemd or Kubernetes
- **Monitoring**: use `/api/v1/health` endpoint for healthchecks on all server instances
