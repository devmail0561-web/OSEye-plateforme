Adapté aux petits environnements (jusqu'à ~50 agents). Tout tourne sur un seul serveur Linux.

## Architecture

```
Internet
  └─► nginx :443 (HTTPS)
        ├── /api/*  → oseye-server:8000
        ├── /ws/*   → oseye-server:8000
        └── /*      → UI (hébergée séparément via OSEYE_UI_URL, ou locale via OSEYE_UI_DIR)

oseye-server ──► postgres  (réseau interne Docker)
             ──► redis     (réseau interne Docker)
             :50051 ──► Agents mTLS (exposé à l'extérieur)
```

## Installation en 3 commandes

<Steps>

1. **Initialiser la PKI**

   Génère la CA, les certificats serveur (avec SANs), les JWT keys et la clé enrollment :

   ```bash
   docker run --rm \
     -v /etc/oseye:/etc/oseye \
     oseye-server:latest \
     oseye-server init
   ```

   <Aside type="caution">
   `/etc/oseye/certs/ca.key` signe tous les certificats agents. Protéger ce fichier, ne jamais l'exposer.
   </Aside>

2. **Lancer le wizard de configuration**

   Configure et génère `/etc/oseye/server.env` et `/etc/oseye/secrets.env` automatiquement :

   ```bash
   docker run --rm -it \
     -v /etc/oseye:/etc/oseye \
     oseye-server:latest \
     oseye-server setup
   ```

   Le wizard demande : hostname, ports, base de données, Redis, mots de passe admin/analyst, APIs TI (optionnel). À la fin il affiche un **token d'enrollment** valable 24h.

3. **Lancer la stack**

   ```bash
   docker compose -f infra/docker/docker-compose.prod.yml up -d
   ```

   Le compose lit automatiquement les fichiers générés par `setup` — aucune variable à passer manuellement.

</Steps>

<Aside type="note">
Par défaut le serveur démarre en **mode agent-only**. Pour activer l'API management (dashboard, alertes, règles) : `oseye-server api enable` puis `oseye-server restart`.
</Aside>

## Vérification

```bash
# Santé des containers
docker compose -f infra/docker/docker-compose.prod.yml ps

# Santé API
curl https://<HOSTNAME>/api/v1/health
# → {"status": "ok"}

# Events reçus des agents
docker logs oseye-server | grep batch_ingested
```

## Enroller les agents

Sur chaque machine à surveiller :

```bash
# Installer
sudo dpkg -i oseye-agent_amd64.deb   # Debian/Ubuntu
sudo rpm -i  oseye-agent_amd64.rpm   # RHEL/Rocky

# Enroller avec le token affiché par setup
sudo oseye-config enroll \
  --server <HOSTNAME>:50051 \
  --token <TOKEN>

sudo systemctl enable --now oseye-agent
```

Pour créer un nouveau token si l'ancien a expiré :

```bash
# Serveur natif (systemd)
sudo oseye-server enrollment token create --valid-hours 24

# Serveur Docker
docker exec oseye-server oseye-server enrollment token create

# Lister les tokens actifs
oseye-server enrollment token list

# Révoquer un token compromis
sudo oseye-server enrollment token revoke <TOKEN_ID>
```

L'agent doit apparaître dans **UI → Agents** avec le statut **Connected**.

## Mise à jour sans perte de données

```bash
docker compose -f infra/docker/docker-compose.prod.yml pull
docker compose -f infra/docker/docker-compose.prod.yml up -d
```

Les volumes PostgreSQL et les certificats sont persistants.
