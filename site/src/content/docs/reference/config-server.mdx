All settings are read from environment variables with the prefix `OSEYE_`.
The `oseye-server` CLI generates `/etc/oseye/server.env` and `/etc/oseye/secrets.env` automatically.

<Aside type="caution" title="Secrets file">
  `/etc/oseye/secrets.env` must be mode **600** and owned by root. It contains passwords, API keys, and (for PostgreSQL) the database URL.
</Aside>

## Commandes CLI

```bash
# Initialiser la PKI
sudo oseye-server init

# Wizard interactif — génère server.env + secrets.env
sudo oseye-server setup

# Cycle de vie
sudo oseye-server start
sudo oseye-server stop    [--timeout 30]
sudo oseye-server restart [--timeout 30]
oseye-server status

# Valider la configuration
sudo oseye-server validate

# Utilisateurs (stockés dans /etc/oseye/users.json)
sudo oseye-server user create <username> --role admin|analyst
sudo oseye-server user passwd <username>
sudo oseye-server user delete <username>
oseye-server user list

# Tokens d'enrollment (connexion directe à la DB)
sudo oseye-server enrollment token create [--valid-hours 24]
oseye-server enrollment token list
sudo oseye-server enrollment token revoke <TOKEN_ID>

# API management
oseye-server api enable          # Activer l'API management
oseye-server api disable         # Désactiver (mode agent-only)
oseye-server api status          # État courant

# UI
oseye-server ui url <URL>        # Configurer OSEYE_UI_URL
oseye-server ui url --unset      # Supprimer OSEYE_UI_URL
```

## API Server

| Variable | Default | Description |
|----------|---------|-------------|
| `OSEYE_API_PORT` | `8000` | REST API listen port |
| `OSEYE_API_HOST` | `0.0.0.0` | REST API bind address |
| `OSEYE_API_CORS_ORIGINS` | `["http://localhost:5173"]` | JSON array of allowed CORS origins |

## gRPC Server

| Variable | Default | Description |
|----------|---------|-------------|
| `OSEYE_GRPC_PORT` | `50051` | Agent gRPC listen port |
| `OSEYE_GRPC_MAX_WORKERS` | `10` | gRPC thread pool size |
| `OSEYE_GRPC_INSECURE_DEV` | `false` | Allow plain-text gRPC — **never `true` in production** |

## Database

| Variable | Default | Description |
|----------|---------|-------------|
| `OSEYE_DB_BACKEND` | `sqlite` | `sqlite` \| `postgresql` \| `clickhouse` |
| `OSEYE_DB_URL` | `sqlite+aiosqlite:///./oseye_dev.db` | SQLAlchemy async URL. For PostgreSQL, store in `secrets.env` (contains password). |
| `OSEYE_DB_POOL_SIZE` | `10` | Connection pool size |
| `OSEYE_DB_MAX_OVERFLOW` | `20` | Max overflow connections |

## Redis (Event Bus)

| Variable | Default | Description |
|----------|---------|-------------|
| `OSEYE_REDIS_URL` | `redis://localhost:6379/0` | Redis connection URL |

## TLS / PKI

| Variable | Default | Description |
|----------|---------|-------------|
| `OSEYE_TLS_CERT_FILE` | `/etc/oseye/certs/server.crt` | Server TLS certificate |
| `OSEYE_TLS_KEY_FILE` | `/etc/oseye/certs/server.key` | Server TLS private key |
| `OSEYE_TLS_CA_CERT_FILE` | `/etc/oseye/certs/ca.crt` | CA certificate (agent mTLS verification) |
| `OSEYE_TLS_CA_KEY_FILE` | `/etc/oseye/certs/ca.key` | CA private key (enrollment signing) |
| `OSEYE_TLS_CA_KEY_PASSWORD` | _(empty)_ | Passphrase for the CA key. Set in `secrets.env`. |

## Mode API et UI

| Variable | Type | Défaut | Description |
|---|---|---|---|
| `OSEYE_MANAGEMENT_API_ENABLED` | bool | `false` | Active l'API management (auth, alertes, décisions, règles, cas…). Par défaut seuls `/health` et `/enroll/*` sont exposés. Mettre `true` pour accès dashboard ou API clients. |
| `OSEYE_UI_URL` | string | — | URL du serveur UI (ex: `https://ui.example.com`). Ajouté automatiquement aux CORS + redirect `GET /` vers cette URL. |
| `OSEYE_UI_DIR` | string | — | Répertoire `dist/` de l'UI buildée, si l'UI est servie depuis **ce** serveur. Indépendant de `OSEYE_UI_URL`. |

## Déploiement distribué

Variables pour les déploiements multi-serveurs.

| Variable | Type | Défaut | Description |
|---|---|---|---|
| `OSEYE_SERVER_ROLE` | `all\|collector\|worker\|api` | `all` | Rôle du nœud : composants démarrés sélectivement |
| `OSEYE_GRPC_SERVER_ENABLED` | bool | `true` | Activer le serveur gRPC (agents). Défaut `false` pour role=api |
| `OSEYE_ML_WORKER_ENABLED` | bool | `true` | Worker ML. Activer sur un seul nœud en distribué |
| `OSEYE_RULE_WORKER_ENABLED` | bool | `true` | Worker règles YAML |
| `OSEYE_DECISION_WORKER_ENABLED` | bool | `true` | Worker Decision Engine |

**Redis requis pour la synchronisation multi-serveurs :**

| Clé Redis | Rôle |
|---|---|
| `oseye:jwt:revoked:{jti}` | Blocklist JWT partagée |
| `oseye:ws:alerts`, `oseye:ws:decisions` | Pub/sub WebSocket entre serveurs |
| `oseye:policy:connected_agents` | CNs agents connectés (tous serveurs) |
| `oseye:decision:leader` | Élection leader pour le journal BLAKE3 |

## Authentication (JWT RS256)

| Variable | Default | Description |
|----------|---------|-------------|
| `OSEYE_JWT_PRIVATE_KEY_PATH` | `/etc/oseye/certs/jwt_private.pem` | RSA-4096 private key for token signing |
| `OSEYE_JWT_PUBLIC_KEY_PATH` | `/etc/oseye/certs/jwt_public.pem` | RSA-4096 public key for token verification |
| `OSEYE_JWT_ACCESS_TOKEN_EXPIRE_MINUTES` | `15` | Access token lifetime (minutes) |
| `OSEYE_JWT_REFRESH_TOKEN_EXPIRE_DAYS` | `7` | Refresh token lifetime (days) |

## Secrets (secrets.env only)

| Variable | Description |
|----------|-------------|
| `OSEYE_SECRET_KEY` | **Required.** HMAC secret for API key signing (hex, 32+ bytes) |
| `OSEYE_ADMIN_PASSWORD` | **Required.** Admin account password (12+ chars) |
| `OSEYE_ANALYST_PASSWORD` | **Required.** Analyst account password (12+ chars) |
| `OSEYE_DB_PASSWORD` | Database password (PostgreSQL only) |

## Decision Engine

| Variable | Default | Description |
|----------|---------|-------------|
| `OSEYE_DECISION_HUMAN_TIMEOUT_SECS` | `3600` | Timeout waiting for human approval |
| `OSEYE_DECISION_HUMAN_POLL_INTERVAL` | `30` | Human decision poll interval (seconds) |
| `OSEYE_DECISION_POLICY_VERSION` | `v1.0` | Active policy version |
| `OSEYE_DECISION_WEIGHT_RULE` | `0.4` | Rule score weight (must sum to 1.0 with other weights) |
| `OSEYE_DECISION_WEIGHT_ML` | `0.3` | ML score weight |
| `OSEYE_DECISION_WEIGHT_TI` | `0.2` | Threat intelligence score weight |
| `OSEYE_DECISION_WEIGHT_DEPTH` | `0.1` | Correlation depth weight |

<Aside type="note" title="Weights constraint">
  `OSEYE_DECISION_WEIGHT_RULE + _ML + _TI + _DEPTH` must equal **1.0** (±0.001). The server refuses to start if the sum is invalid.
</Aside>

## Plugins

| Variable | Default | Description |
|----------|---------|-------------|

## Surveillance & Agent Autonomy

| Variable | Default | Description |
|----------|---------|-------------|
| `OSEYE_DEFAULT_SURVEILLANCE_PROFILE` | `workstation` | Profile pushed to agents on connect |
| `OSEYE_AGENT_DEFAULT_AUTONOMY` | `critical_only` | Fallback autonomy level |
| `OSEYE_RULE_SIGNING_KEY_PATH` | _(unsigned)_ | Ed25519 private key for signing rule sets pushed to agents |

### Surveillance profiles

| Profile | Description |
|---------|-------------|
| `workstation` | Standard desktop monitoring |
| `server` | Production server (full collectors) |
| `investigation` | Deep monitoring — all events, no throttle |
| `minimal` | Reduced collection for low-resource systems |
| `compliance` | Focused on audit/compliance events |
| `stealth` | Minimal footprint, reduced logging |
