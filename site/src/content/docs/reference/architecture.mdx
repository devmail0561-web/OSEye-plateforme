## Agent Components

| Component | Technology | Role |
|-----------|-----------|------|
| Collectors | eBPF (cilium/ebpf), auditd, fanotify, inotify, procfs, netlink, journald, udev, syslog | Event collection |
| Batcher | Go channels | Batch events for efficient transport |
| Hash Chain | BLAKE3 | Tamper-evident event integrity |
| Signer | Ed25519 | Batch authentication |
| Buffer | SQLite | Offline durability |
| Transport | gRPC + mTLS TLS 1.3 | Secure server communication |
| Responder | nftables, syscall | Execute response actions |
| Watchdog | procfs polling | CPU/RAM throttling |
| Policy Client | gRPC stream | Receive profile changes |

## Server Components

| Component | Technology | Role |
|-----------|-----------|------|
| Normalizer | Python dataclass | Unified event format |
| Rule Engine | YAML rules | Pattern-based detection |
| ML Engine | River (HalfSpaceTrees) | Anomaly detection |
| TI Engine | HTTP clients | Threat intelligence enrichment |
| Correlation | Stateful engine | Multi-event incident reconstruction |
| Decision Engine | Risk matrix | Autonomous response decisions |
| Response Engine | gRPC commands | Send actions to agents |
| Plugin System | Unix socket IPC | Extensibility |
| REST API | FastAPI | Dashboard + external integrations |
| WebSocket | Starlette | Real-time event streaming |

## Data Flow

1. **Collection**: Agent collectors produce raw events
2. **Batching**: Events are batched (configurable size/timeout)
3. **Signing**: Each batch gets BLAKE3 chain hash + Ed25519 signature
4. **Buffer**: Batch written to SQLite buffer (durability)
5. **Transport**: Sent via gRPC/mTLS to server
6. **Normalization**: Server converts to UniversalEvent format
7. **Analysis**: Parallel processing through Rule/ML/TI engines
8. **Correlation**: Related events grouped into incidents
9. **Decision**: Risk assessment and response determination
10. **Response**: Commands sent back to agents if needed
11. **Storage**: Events persisted to PostgreSQL/ClickHouse

## Security Design

| Layer | Mechanism |
|-------|-----------|
| Transport | mTLS (TLS 1.3 only) |
| Integrity | BLAKE3 hash chain per event |
| Authentication | Ed25519 signature per batch |
| Audit | Immutable BLAKE3 decision journal |
| Authorization | JWT + RBAC (admin, analyst, viewer) |
| Plugins | Ed25519 signature verification |
| Availability | Offline buffer + backoff + watchdog |
