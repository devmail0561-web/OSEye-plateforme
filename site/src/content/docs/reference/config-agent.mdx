## Configuration File

The agent reads environment variables from `/etc/oseye/agent.env` (loaded by systemd).

Override the path with: `OSEYE_ENV_FILE=/path/to/file`

## All Variables

### Connection

| Variable | Type | Default | Validation |
|----------|------|---------|------------|
| `OSEYE_GRPC_ADDR` | string | `localhost:50051` | Must be `host:port`, port 1-65535 |
| `OSEYE_TLS_CERT` | path | — | Must be absolute path |
| `OSEYE_TLS_KEY` | path | — | Must be absolute path |
| `OSEYE_TLS_CA` | path | — | Must be absolute path |
| `OSEYE_ENROLL_URL` | URL | — | Must be http:// or https:// |
| `OSEYE_ENROLL_TOKEN` | string | — | Sensitive (masked in output) |

### Identity

| Variable | Type | Default | Validation |
|----------|------|---------|------------|
| `OSEYE_AGENT_ID` | UUID | auto-generated | Must be valid UUID v4 (if set) |

### Performance Tuning

| Variable | Type | Default | Validation |
|----------|------|---------|------------|
| `OSEYE_BATCH_SIZE` | int | `1000` | Range: 1–100000 |
| `OSEYE_BATCH_TIMEOUT_MS` | int | `1000` | Must be positive |
| `OSEYE_MAX_CPU_PCT` | float | `4.0` | Range: 0–100 |
| `OSEYE_MAX_MEM_MB` | int | `256` | Must be > 0 |

### Storage

| Variable | Type | Default | Validation |
|----------|------|---------|------------|
| `OSEYE_BUFFER_PATH` | path | `/var/lib/oseye/buffer.db` | Must be absolute path |
| `OSEYE_QUARANTINE_DIR` | path | `/var/lib/oseye/quarantine` | Absolute, not critical path |

Critical paths rejected for quarantine: `/`, `/bin`, `/sbin`, `/usr`, `/lib`, `/boot`, `/etc`, `/dev`, `/proc`, `/sys`

### Cryptography

| Variable | Type | Default | Validation |
|----------|------|---------|------------|
| `OSEYE_ED25519_SIGNING_KEY` | path | `/etc/oseye/certs/agent.ed25519.key` | Must be absolute path |
| `OSEYE_INSECURE_KEY_PERMS` | bool | `false` | Autoriser le démarrage si la clé Ed25519 a des permissions > 0600. **Développement uniquement** — ne jamais utiliser en production. |

### Collection

| Variable | Type | Default | Validation |
|----------|------|---------|------------|
| `OSEYE_FANOTIFY_PATHS` | CSV | `/` | Each must be absolute path |
| `OSEYE_INOTIFY_WATCHES` | JSON | — | Array of `{path, recursive, mask}` |
| `OSEYE_JOURNALD_PRIORITY` | string | `warning` | — |
| `OSEYE_JOURNALD_UNITS` | CSV | — | Comma-separated unit names |
| `OSEYE_SYSLOG_ADDR` | string | `127.0.0.1:514` | Must be `host:port`, port 1-65535 |

### Inotify Watches Format

```json
[
  {"path": "/etc", "recursive": true, "mask": 4095},
  {"path": "/home", "recursive": false, "mask": 256}
]
```

## CLI Tool

Use `oseye-config` to manage configuration safely:

```bash
oseye-config show          # Display effective config
oseye-config validate      # Check all values
oseye-config get KEY       # Read a value
oseye-config set KEY=VAL   # Write (with validation)
oseye-config unset KEY     # Remove (revert to default)
oseye-config check-files   # Verify certs/dirs exist
oseye-config version       # Show tool version
```

Security features:
- Atomic writes (temp + fsync + rename)
- File locking (flock LOCK_EX)
- Newline injection rejection
- Sensitive keys masked in output
- Dry-run validation before writing
