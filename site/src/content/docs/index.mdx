## Architecture

```
[Agent Go — static binary]  ──gRPC/mTLS──►  [Server Python — Docker or pip]
  Linux: eBPF, auditd, procfs,               Rule Engine (35+ YAML rules)
         fanotify, inotify, netlink,          ML Engine (online HalfSpaceTrees)
         journald, udev, syslog               TI Engine (AbuseIPDB, VT, MISP)
  Windows: ETW, Sysmon, WMI (roadmap)         Correlation → Decision → Response
  macOS: Endpoint Security (roadmap)          Plugin System (IPC socket)
  Buffer SQLite (offline resilience)          PostgreSQL + Redis + Dashboard
  Responder (kill/block/quarantine)           FastAPI + WebSocket → React UI
```

## Quick Start

```bash
# Install agent on Debian/Ubuntu (single binary, no dependencies)
curl -fsSL https://oseye.github.io/oseye/install.sh | sudo bash

# Or download the .deb/.rpm directly from GitHub Releases
curl -LO https://github.com/oseye/oseye/releases/latest/download/oseye-agent_amd64.deb
sudo dpkg -i oseye-agent_amd64.deb

# Deploy server with Docker Compose (recommended)
git clone https://github.com/oseye/oseye.git && cd oseye
sudo bash scripts/init-server.sh
docker compose -f infra/docker/docker-compose.prod.yml up -d

# Enroll the agent
sudo oseye-config set OSEYE_GRPC_ADDR=server.example.com:50051
sudo systemctl start oseye-agent

# Check status
sudo oseye-config validate
```
