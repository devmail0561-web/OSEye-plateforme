## Serveur

<Aside type="caution" title="Nœud dédié recommandé">
  Le serveur nécessite PostgreSQL, Redis et au minimum 2 Go de RAM. Ne pas installer sur un hôte surveillé par un agent OSEye.
</Aside>

<Tabs>
  <TabItem label="Debian / Ubuntu (.deb)">
    ```bash
    curl -LO https://github.com/devmail0561-web/OSEye-plateforme/releases/latest/download/oseye-server_amd64.deb
    curl -LO https://github.com/devmail0561-web/OSEye-plateforme/releases/latest/download/oseye-server_amd64.deb.asc
    gpg --verify oseye-server_amd64.deb.asc oseye-server_amd64.deb
    sudo dpkg -i oseye-server_amd64.deb
    sudo oseye-server init    # génère le PKI et les répertoires système
    sudo oseye-server setup   # assistant interactif (DB, Redis, TLS, credentials)
    sudo systemctl enable --now oseye-server
    ```
  </TabItem>
  <TabItem label="RHEL / Fedora (.rpm)">
    ```bash

    sudo rpm -i oseye-server_amd64.rpm
    sudo oseye-server init
    ```

  </TabItem>

    ```bash

    docker run --rm \
      -v /etc/oseye:/etc/oseye \
      ghcr.io/devmail0561-web/oseye-server:latest \

    docker run --rm -it \
      -v /etc/oseye:/etc/oseye \
      ghcr.io/devmail0561-web/oseye-server:latest \
      oseye-server setup

    # Lancement stack complète (server + PostgreSQL + Redis + UI)
    docker compose -f infra/docker/docker-compose.prod.yml up -d
    curl https://localhost:8000/api/v1/health
    ```

## Package développeur

### Package développeur (`oseye-dev`)

Package tout-en-un pour les développeurs — agent + serveur préconfigurés pour le développement.
Installe et démarre automatiquement.

```bash
# Debian/Ubuntu
sudo apt install ./oseye-dev_0.3.0-alpha.1_amd64.deb

# RHEL/Rocky
sudo rpm -i oseye-dev-0.3.0-alpha.1.x86_64.rpm
```

Après installation :
- **API** : http://localhost:8000/api/v1/health
- **Admin** : admin123
- **Logs** : `journalctl -u oseye-dev -f`

### Installation one-shot

```bash
bash install.sh
```

Installe les prérequis, génère les certificats, configure et lance la stack production.

## Vérification d'intégrité (SHA-256)

Chaque release publie un fichier `SHA256SUMS` signé GPG. Pour vérifier tous les artefacts d'un coup :

```bash
curl -LO https://github.com/devmail0561-web/OSEye-plateforme/releases/latest/download/SHA256SUMS
curl -LO https://github.com/devmail0561-web/OSEye-plateforme/releases/latest/download/SHA256SUMS.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing
```

## Prérequis système

| Composant | Minimum | Recommandé |
|-----------|---------|------------|
| OS | Linux 5.10+, x86-64 | Linux 6.x, x86-64 |
| Agent CPU | 1 cœur | 2 cœurs |
| Agent RAM | 128 Mo | 256 Mo |
| Agent Disk | 500 Mo | 2 Go (buffer) |
| Server CPU | 2 cœurs | 4 cœurs |
| Server RAM | 2 Go | 8 Go |
| Server Disk | 10 Go | 100 Go (événements) |

Après le téléchargement, suivre [Installation](/OSEye-plateforme/getting-started/installation/) pour la configuration complète.
