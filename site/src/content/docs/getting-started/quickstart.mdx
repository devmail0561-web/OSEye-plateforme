## Prerequisites

- Linux server with kernel 5.10+ (eBPF support)
- Go 1.23+ (for building from source)
- Python 3.12+ (for the server)

## Step 1: Start the Server

```bash
git clone https://github.com/oseye/oseye.git
cd oseye

# Generate dev certificates
./scripts/generate_certs.sh

# Start server (SQLite + in-memory bus)
make run-server
```

The server starts on port 8000. Verify:
```bash
curl http://localhost:8000/api/v1/health
```

## Step 2: Start the Agent

In a new terminal:
```bash
# Start agent (connects to localhost:50051)
make run-agent
```

The agent starts collecting events and buffering them locally.

## Step 3: Open the Dashboard

```bash
make ui-dev
```

Open http://localhost:5173 in your browser. You should see events flowing in real-time.

## Step 4: First Detection

Create a test detection by triggering a rule:

```bash
# This triggers the "suspicious_passwd_read" rule
cat /etc/shadow 2>/dev/null || true
```

Check the Alerts page in the dashboard within a few seconds.
