Ce guide utilise les **packages précompilés** — pas besoin de compiler le code source.

<Aside type="note">
L'agent requiert Linux avec kernel 5.10+ pour les collecteurs eBPF. macOS et Windows sont en développement.
</Aside>

---

## Stack complète en mode développement

<Steps>

1. **Lancer la stack serveur**

   Cloner le dépôt et démarrer avec Docker Compose :

   ```bash
   git clone https://github.com/devmail0561-web/OSEye-plateforme.git
   cd OSEye-plateforme

   # Construire les images
   make package-server

   # Lancer postgres, redis, serveur et UI
   docker compose -f infra/docker/docker-compose.dev.yml up -d
   ```

   Vérifier que tout est sain :
   ```bash
   docker compose -f infra/docker/docker-compose.dev.yml ps
   curl http://localhost:5174/api/v1/health
   # → {"status": "ok"}
   ```

2. **Installer l'agent**

   ```bash
   # Construire le package agent
   make package-agent

   # Installer
   sudo dpkg -i dist/oseye-agent_*_amd64.deb
   ```

3. **Créer un token d'enrollment**

   ```bash
   docker exec oseye-server oseye-server enrollment token create
   # → TOKEN: abc123...
   ```

4. **Enroller l'agent**

   ```bash
   sudo oseye-config enroll \
     --server localhost:50051 \
     --token <TOKEN>
   ```

   L'enrollment génère les certificats mTLS et configure le service systemd automatiquement.

5. **Ouvrir l'UI**

   Ouvrir http://localhost:5174 dans le navigateur.

   **Login :** `admin / admin123`

   La page **Agents** doit montrer l'agent connecté. La page **Events** montre les événements en temps réel.

</Steps>

---

## Première détection

Déclencher la règle `suspicious_passwd_read` :

```bash
cat /etc/shadow 2>/dev/null || true
```

Vérifier la page **Alertes** dans l'UI — une alerte doit apparaître en quelques secondes.
