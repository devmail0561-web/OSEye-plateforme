## Overview

The OSEye dashboard is a React/TypeScript single-page application providing real-time visibility into your security posture.

## Pages

### Events

Real-time stream of all collected events. Features:
- Live WebSocket updates
- Filterable by type, source, severity, agent
- Timeline visualization
- Event detail panel with full payload

### Alerts

Active alerts generated by detection rules and ML anomalies:
- Severity badges (critical, high, medium, low)
- MITRE ATT&CK technique tags
- Quick actions (acknowledge, escalate, dismiss)
- Grouping by rule or source

### Incidents

Correlated multi-event incidents:
- Automatic correlation by entity (process tree, IP, user)
- Timeline reconstruction
- Impact assessment score
- Status workflow (open → investigating → resolved → closed)

### Decisions

Autonomous decisions made by the Decision Engine:
- Decision type and risk level
- Response action taken
- Immutable audit trail (BLAKE3 hash chain)
- Admin override/rollback capability

### Cases (Forensics)

Investigation cases for deep analysis:
- Evidence attachment
- Custody log (chain of evidence)
- Export to PDF, MISP, TheHive
- Analyst notes and collaboration

### Admin Pages

Role-based access for administrators:
- **Agents**: connected agents, status, profiles
- **Rules**: rule management, enable/disable, statistics
- **Plugins**: installed plugins, upload new ones
- **Users**: RBAC user management
- **Settings**: server configuration, profiles

## Navigation

The sidebar is collapsible and organizes pages by function:
- **Monitor**: Events, Alerts, Incidents
- **Respond**: Decisions, Response Actions
- **Investigate**: Cases, Forensics
- **Configure**: Rules, Plugins, Agents, Settings

## Real-time Updates

All pages receive live updates via WebSocket. No manual refresh needed. A connection indicator shows the WebSocket status.
