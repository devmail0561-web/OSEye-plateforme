## Overview

The Plugin SDK allows extending OSEye with custom logic without modifying the core codebase. Plugins run in sandboxed processes communicating over an IPC channel — Unix socket on Linux and macOS, named pipe on Windows (in development).

## Plugin Types

| Type | Purpose | Example |
|------|---------|---------|
| `AnalyzerPlugin` | Custom event analysis | YARA scanner, custom ML model |
| `ExporterPlugin` | Export events/alerts externally | Slack notifier, SIEM forwarder |
| `CollectorPlugin` | Custom event source | Application-specific logs |

## Writing a Plugin

### 1. Install the SDK

```bash
pip install oseye-sdk
```

### 2. Create a Plugin

```python
from oseye_sdk.plugin import ExporterPlugin
from oseye_sdk.event import Event

class SlackNotifier(ExporterPlugin):
    name = "notifier_slack"
    version = "1.0.0"

    def on_start(self) -> None:
        self.webhook_url = self.config.get("webhook_url")

    def on_stop(self) -> None:
        pass

    def export(self, event: Event) -> None:
        if event.severity == "critical":
            self._send_slack(event)

    def _send_slack(self, event: Event) -> None:
        import requests
        requests.post(self.webhook_url, json={
            "text": f"[{event.severity.upper()}] {event.description}"
        })
```

### 3. Package and Sign

```bash
# Generate signing key (first time)
oseye-sdk keygen --output my-plugin.key

# Package
oseye-sdk package ./my_plugin/ --sign my-plugin.key --output notifier_slack.ospkg
```

### 4. Upload

Upload via the dashboard (Admin → Plugins → Upload) or API:

```bash
curl -X POST https://server:8000/api/v1/plugins/upload \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -F "plugin=@notifier_slack.ospkg"
```

### Via CLI (le serveur n'a pas besoin de tourner)

```bash
# Upload avec vérification de signature (défaut)
sudo oseye-server plugin upload my_plugin.py --sig my_plugin.sig

# Upload sans vérification (développement uniquement)
sudo oseye-server plugin upload my_plugin.py --no-verify

# Lister les plugins installés
oseye-server plugin list
```

Redémarrer le serveur après upload : `oseye-server restart`

## Signature Verification

In production (`OSEYE_PLUGIN_REQUIRE_SIGNATURE=true`), all plugins must be signed with Ed25519. The server verifies the signature before loading.

Register trusted public keys:

```bash
curl -X POST https://server:8000/api/v1/plugins/keys \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "team-key", "public_key": "base64-encoded-ed25519-pubkey"}'
```

### Security Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `OSEYE_PLUGIN_REQUIRE_SIGNATURE` | `true` | Require Ed25519 signature verification before loading a plugin. |
| `OSEYE_PLUGIN_STRICT_NETNS` | `false` | Si `true`, le lancement d'un plugin échoue si l'isolation réseau (unshare CLONE_NEWNET) n'est pas disponible. Activer en production. |

## Plugin Lifecycle

1. **Upload** → signature verified, stored in plugins directory
2. **Load** → spawned as subprocess, IPC socket connected
3. **Start** → `on_start()` called, plugin ready
4. **Run** → events dispatched to plugin methods
5. **Stop** → `on_stop()` called on server shutdown or plugin disable
6. **Unload** → process terminated, socket closed

## Configuration

Plugins receive configuration from the server:

```yaml
# Plugin config (set via dashboard or API)
notifier_slack:
  webhook_url: "https://hooks.slack.com/services/..."
  min_severity: "high"
```

Access in the plugin:
```python
def on_start(self) -> None:
    self.webhook_url = self.config["webhook_url"]
    self.min_severity = self.config.get("min_severity", "critical")
```
